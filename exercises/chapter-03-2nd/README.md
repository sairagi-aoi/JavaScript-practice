# 第3章 3-7〜3-11の復習（2周目）

このフォルダは、[第3章 3-7〜3-11の復習](../chapter-03/README.md)（1周目）と同じ範囲の2周目です。対応するのは『1冊ですべて身につくJavaScript入門講座』の p.70〜90（3-7 定数、3-8 イベント、3-9 関数、3-10 スタイル、3-11 条件分岐）です。1周目を終えたあとに、別の題材でもう一度解いて、なぜその書き方になるのかを確かめるための問題です。

使える書き方は1周目と同じ範囲です。

| 順番 | 練習問題 | 対応する節 | 主に使うこと |
| --- | --- | --- | --- |
| 01 基礎 | [定数名の誤りを直して会場案内を2枚出す](01-venue-signs/README.md) | 3-7 定数 | 命名ルール、予約語、ReferenceError、定数の再利用 |
| 02 基礎 | [買い物当番の一文を関数で再利用する](02-shopping-duty/README.md) | 3-9 関数 | 仮引数と実引数、戻り値、同じ関数の再利用 |
| 03 応用 | [花束の札で名前付き関数と無名関数を書き分ける](03-flower-labels/README.md) | 3-8 イベント、3-9 関数 | `input`、名前付き関数と無名関数、関数名の渡し方 |
| 04 応用 | [カフェの席案内で else if の順を確かめる](04-cafe-guide/README.md) | 3-11 条件分岐 | `===`、`else if` の評価順 |

並びは教科書の節順ではなく、基礎（定数・関数）から応用（イベント・条件分岐・`style`）、最後に総合へ進む順です。

## 取り組み方

1. 問題の入ったファイルを手元に用意します。
   - まだ `main` にマージしていないときは、GitHubでブランチ `practice/chapter-3-review-2` を選んでから **Code → Download ZIP** を押します。クローン済みなら `git checkout practice/chapter-3-review-2` です。ブランチを選ばずにZIPを落とすと、入るのは `main` で、この2周目のフォルダは含まれません。
   - `main` へマージしたあとは、ブランチを `main` にしたまま **Code → Download ZIP** を押すか、`git checkout main` で同じ問題を取れます。
2. 各問には、問題文の `README.md` と作業用の `index.html` があります。手元の `index.html` をエディターとブラウザーの両方で開き、末尾の `<script>` に自分のコードを書いてください。HTMLの入力欄や表示欄は用意してあります。
3. 書いたら保存し、ブラウザーを再読み込みして「完了条件」を上から試します。問02の出力は開発者ツールの「コンソール」でも確認します。問05の文字サイズと背景色、問06の背景色は、要素を右クリックして「検証」を開き、計算済みスタイルで確かめられます。
4. 解答例は各問のREADMEの末尾に折りたたんであります。先に自分のコードを書き、完了条件を試してから開いてください。開いたら「答え合わせの観点」で、画面に出ていても条件を外していないところがないか比べます。

手が止まったら「何を読むか」「何をきっかけにするか」「どこに何を表示するか」を書き出してみてください。各問のヒントはクリックすると開きます。
