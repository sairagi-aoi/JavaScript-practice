# 04　カフェの席案内で else if の順を確かめる

**難易度**　★★☆ 応用

**目的**　2つの条件が同時に成り立つとき、`else if` は上から順に見て、最初に一致した分岐だけを実行する。順番を入れ替えると、同じ入力でも案内が変わる。

カフェの入口で、席の希望 `#seat` と杯 `#cup` から案内 `#guide` を1つ出します。判定はこの順です。

1. `#seat` が `窓` なら「窓側の席へどうぞ」。
2. そうでなく、`#cup` が `マグ` なら「マグはカウンターです」。
3. どちらでもなければ「店員に聞いてください」。

席が「窓」で杯が「マグ」のときは、1が先に一致するので2は見ません。次のように杯を先に書くと、同じ入力で「マグはカウンターです」になります。上の1番に合わせるなら、席の条件を先に書きます。

```js
if (cup.value === 'マグ') {
  guide.textContent = 'マグはカウンターです';
} else if (seat.value === '窓') {
  guide.textContent = '窓側の席へどうぞ';
} else {
  guide.textContent = '店員に聞いてください';
}
```

ページを開いたときに一度判定し、どちらの入力が変わったときも同じ関数で判定し直します。比較は `===` です。「窓際」や「マグカップ」は一致しません。

| 席 | 杯 | 案内 |
| --- | --- | --- |
| （空） | （空） | 店員に聞いてください |
| 窓 | マグ | 窓側の席へどうぞ |
| 窓 | グラス | 窓側の席へどうぞ |
| 店内 | マグ | マグはカウンターです |
| 店内 | グラス | 店員に聞いてください |
| 窓際 | グラス | 店員に聞いてください |
| 窓際 | マグ | マグはカウンターです |

## 完了条件

- [ ] 開いた直後は両方とも空なので「店員に聞いてください」が出る。
- [ ] 席を「窓」、杯を「マグ」にすると「窓側の席へどうぞ」になる。杯がマグでも、席の条件が先に採用される。
- [ ] その状態から席を「店内」に変えると「マグはカウンターです」になる。
- [ ] 杯を「グラス」に変えると「店員に聞いてください」になる。席が「窓」のまま杯だけ「グラス」なら「窓側の席へどうぞ」のまま。
- [ ] 「窓」のうしろに「際」を足して「窓際」にしたとき、杯が「マグ」なら「マグはカウンターです」、杯が「マグ」でなければ「店員に聞いてください」に、欄から離れる前に変わる。

<details>
<summary>ヒント</summary>

席が窓で杯がマグのときに出したい文を先に決めます。その文の条件を `if` の最初に置き、もう一方は `else if` にします。先に一致した時点で、うしろの分岐は実行されません。

</details>

<summary>解答例</summary>

自分のコードを書いてから開いてください。

### 答え合わせの観点

- 最初の条件は `seat.value === '窓'` です。杯がマグでも、席が窓なら「窓側の席へどうぞ」になります。
- マグの判定は `else if` なので、席が窓のときには実行されません。この2つの条件を逆にすると、窓かつマグの案内が「マグはカウンターです」に変わります。
- 比較は `===` です。「窓際」は席の条件に一致しませんが、杯が「マグ」なら次の分岐が選ばれます。「マグカップ」は杯の条件に一致しませんが、席が「窓」なら最初の分岐が選ばれます。
- 開いたときに一度呼び、席と杯の `input` が同じ関数を呼んでいます。1文字足した瞬間に案内が変わります。

```js
const seat = document.querySelector('#seat');
const cup = document.querySelector('#cup');
const guide = document.querySelector('#guide');

function updateGuide() {
  if (seat.value === '窓') {
    guide.textContent = '窓側の席へどうぞ';
  } else if (cup.value === 'マグ') {
    guide.textContent = 'マグはカウンターです';
  } else {
    guide.textContent = '店員に聞いてください';
  }
}

updateGuide();
seat.addEventListener('input', updateGuide);
cup.addEventListener('input', updateGuide);
```
