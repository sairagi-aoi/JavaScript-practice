# 02　ラジオの曲紹介を返す関数を書く

**難易度**　★☆☆ 基礎

**目的**　引数で受け取ったデータを文字列にして返し、呼び出した側でその使い道を選ぶ。

番組の「再生中」欄と放送記録には、同じ形式の曲紹介を使います。曲名、演奏者の順に2つの引数を受け取る関数 `formatTrack` を作ってください。関数の仕事は紹介文を返すところまでです。ページやコンソールへの出力は呼び出し側に書きます。関数宣言とアロー関数は、どちらを使っても構いません。

| 曲名 | 演奏者 | 返す文字列 |
| --- | --- | --- |
| 星を拾う | 波止場トリオ | 星を拾う（波止場トリオ） |
| 夜の窓 | にじ | 夜の窓（にじ） |

## 完了条件

- [ ] 1曲目の戻り値を定数で受け取り、ページの `#nowPlaying` とコンソールの1行目に同じ紹介文を出せる。
- [ ] 同じ関数に2曲目を渡すと、コンソールの2行目に2曲目が出る。ページの「再生中」欄には1曲目が表示されている。
- [ ] 関数の中身を変えず、好きな曲名と演奏者を渡しても、同じ形式の文字列が返る。

<details>
<summary>ヒント</summary>

関数の外で紹介文を再利用するには、組み立てた文字列が呼び出し元まで届く必要があります。コンソールに文が出てもページが空なら、呼び出し側が受け取った値を確かめましょう。

</details>
