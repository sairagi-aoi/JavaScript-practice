# 第3章 3-7〜3-11の復習

『1冊ですべて身につくJavaScript入門講座』の p.70〜90 に対応するオリジナル演習です。最初は定数の値を2か所に表示し、最後は作品名と受付状況の両方に反応する上映会の入口ボードを作ります。

| 順番 | 練習問題 | 主に使うこと |
| --- | --- | --- |
| 01 基礎 | [集合場所を2枚の案内に反映する](01-meeting-place/README.md) | `const` の命名と再利用、要素の取得、文字列の組み立て |
| 02 基礎 | [ラジオの曲紹介を返す関数を書く](02-radio-track/README.md) | 2つの引数、関数の呼び出し、戻り値 |
| 03 応用 | [落とし物メモを入力中に表示する](03-lost-and-found/README.md) | `input` イベント、`value`、`textContent` |
| 04 応用 | [荷物の受け取り窓口を判定する](04-parcel-desk/README.md) | `===`、`if`・`else if`・`else` |
| 05 応用 | [朗読カードの文字サイズを調整する](05-reading-size/README.md) | `style.fontSize`、CSSの単位、値と表示の同期 |
| 06 小規模実装 | [上映会の入口ボードを作る](06-cinema-board/README.md) | 関数の再利用、2つの入力、文面と背景色の更新 |

## 取り組み方

1. 問題が見えるブランチを手元に用意します。GitHubから取得する場合は、リポジトリのトップで **Code → Download ZIP** を選び、ZIPを展開します。
2. 各問には、問題文の `README.md` と作業用の `index.html` があります。手元の `index.html` をエディターとブラウザーの両方で開き、末尾の `<script>` に自分のコードを書いてください。HTMLの入力欄や表示欄は用意してあります。
3. 書いたら保存し、ブラウザーを再読み込みして「完了条件」を上から試します。問02の出力は開発者ツールの「コンソール」でも確認します。

手が止まったら「何を読むか」「何をきっかけにするか」「どこに何を表示するか」を書き出してみてください。各問のヒントはクリックすると開きます。
